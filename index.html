这个源是干什么的

存放用 C / C++ 编写、在 Termux / Android 上构建或交叉编译后打包成 .deb 的软件包。添加源后即可用 apt 安装升级，无需手动 dpkg -i。

支持平台

  • Termux（Android 手机）
  • 架构：aarch64
  • 格式：Termux 风格 *.deb
  • 不支持 Debian / Ubuntu x86_64（Termux 不兼容）

打包流程

C/C++ 源码
  ↓ 编译（Termux / cross-ng / NDK）
二进制 + control 文件
  ↓ dpkg-deb --build
pool/main/<首字母>/<包名>/xxx_aarch64.deb
  ↓
dpkg-scanpackages → Packages
apt-ftparchive   → Release
  ↓
GitHub Pages 托管 APT 源

添加这个源

mkdir -p $PREFIX/etc/apt/sources.list.d
echo "deb [trusted=yes] https://debmaker-cpp.github.io termux main" \
  > $PREFIX/etc/apt/sources.list.d/debmaker-cpp.list
apt update
apt install epubmaker

[trusted=yes] 表示暂不校验 GPG 签名，适合个人 / 测试源；做签名后改为 signed-by=...。

收包规则

✅ 接受

  • 小包（< 1MB）：工具类、库、脚本封装
  • 中包（1MB ~ 20MB）：编译器、解释器、游戏、完整 C/C++ 项目
  • 自己写的 C/C++ 程序
  • 合法开源软件重新打包（需注明原作者 / 许可证）
  • 能在 Termux aarch64 上运行的 .deb

❌ 拒绝

  • 含病毒、木马、恶意代码、后门的包 —— 删除 + 拉黑
  • 侮辱、攻击、骚扰他人的内容（含包名、描述、注释）
  • 单个 > 50MB 的包 —— 请放 GitHub Releases 或其他托管
  • 盗号程序、挖矿木马、远控木马
  • 违反中国法律与 GitHub ToS 的内容

⚠️ 提交前确认

  • 包名不带侮辱性词汇
  • control 里 Description 写清用途
  • .deb 能在 Termux aarch64 上安装运行
  • 不提交无权限分发的闭源二进制

仓库结构

  • dists/termux/Release
  • dists/termux/main/binary-aarch64/Packages
  • pool/
  • pool/main/

自动更新

往 pool/ push 新的 .deb，GitHub Actions 自动重新生成 Packages、Release 与网页文件列表并 push 回仓库。

注意事项

  • 包必须是 aarch64
  • 不放 Debian / Ubuntu 的 x86_64 .deb
  • 单个 .deb 建议 ≤ 20MB，最大 ≤ 50MB
  • GitHub Pages 单文件 ≤ 100MB（硬限制）

违规处理

  • 第一次：删包 + 警告
  • 第二次：删包 + 移除写入权限
  • 涉及违法内容：举报 GitHub + 配合执法
