debmaker-cpp

debmaker-cpp.github.io —— 一个用 GitHub Pages 托管的 Termux APT 源。

这个仓库是干什么的

这里存放用 C / C++ 编写、在 Termux / Android 手机上构建或交叉编译后， 打包成 .deb 的软件包。 你不用手动 dpkg -i，只要添加源，就能用 apt 安装、升级。

支持平台

  • Termux（Android 手机）
  • 架构：aarch64（手机 ARM64）
  • 格式：Termux 风格 *.deb
  • 不支持：Debian / Ubuntu x86_64 的普通系统包（Termux 不兼容）

C/C++ 打包流程

C/C++ 源码
  ↓ 编译（Termux / cross-ng / NDK）
二进制 + control 文件
  ↓ dpkg-deb --build
pool/main/<首字母>/<包名>/xxx_aarch64.deb
  ↓
dpkg-scanpackages → Packages
apt-ftparchive     → Release
  ↓
GitHub Pages 自动托管 APT 源

在 Termux 里添加这个源

echo "deb [trusted=yes] https://debmaker-cpp.github.io termux main" \
  > $PREFIX/etc/apt/sources.list.d/debmaker-cpp.list

apt update
apt install epubmaker

mkdir -p $PREFIX/etc/apt/sources.list.d [trusted=yes] 表示暂不校验 GPG 签名，适合个人/测试源。 以后做签名后可以写成 signed-by=...。

收包规则

✅ 接受

  • 小包（< 1MB）：工具类、库、脚本封装
  • 中包（1MB ~ 20MB）：编译器、解释器、游戏、完整 C/C++ 项目
  • 自己写的 C/C++ 程序
  • 合法开源软件重新打包（注明原作者/许可证）
  • Termux 里能实际运行的 aarch64 .deb

❌ 拒绝 / 禁止

  • 任何包含病毒、木马、恶意代码、后门的包 —— 发现直接删除 + 拉黑提交者
  • 侮辱、攻击、骚扰他人的内容 —— 包括包名、描述、源码注释中的侮辱性文字
  • 极大包（> 50MB 单个 .deb） —— GitHub Pages 有带宽和单文件限制，超大包请放 Release 或用其他托管
  • 盗号程序、挖矿木马、远程控制木马
  • 违反中国法律和 GitHub ToS 的内容

⚠️ 提交前请确认

  • 包名不要带侮辱性词汇
  • control 文件里的 Description 写清楚用途
  • 确保 .deb 能在 Termux aarch64 上正常安装运行
  • 不要提交你没权限分发的闭源二进制

仓库结构

  • dists/termux/Release
  • dists/termux/main/binary-aarch64/Packages
  • pool/（所有 .deb 文件）
  • pool/main/

可用包示例

  • epubmaker_1.0.0_aarch64.deb

自动更新

往 pool/ 里 push 新的 .deb， GitHub Actions 会自动：

  • 重新生成 Packages
  • 重新生成 Release
  • 重新生成网页文件列表
  • push 回仓库

注意事项

  • 包必须是 aarch64，否则 Termux 装不了
  • 不要放 Debian/Ubuntu 的 x86_64 .deb
  • 单个 .deb 建议 ≤ 20MB，最大不超过 50MB
  • GitHub Pages 单文件 ≤ 100MB（硬限制）

违规处理

  • 第一次提交恶意包：删除包 + 警告
  • 第二次：删除包 + 移除仓库写入权限
  • 涉及违法内容：举报给 GitHub + 配合执法
